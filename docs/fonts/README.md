# Fonts

Roboto, the CitizenGO brand face (Brand Guidelines, Updated Q3 2026), for the burnt-in captions and name plates
in `src/socialcut.py` and `src/speechcut.py`. Static TTFs from the official Roboto release v2.138
(github.com/googlefonts/roboto, `roboto-unhinted.zip`), Apache License 2.0 (`LICENSE-Roboto.txt`).
When these files are present the clip tools use Roboto; otherwise they fall back to Helvetica Neue.
