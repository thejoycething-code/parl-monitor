# Parliamentary Monitor: weekly digest template
**Version 0.1 (draft for review) | 1 August 2026 | Owner: Christopher**

## How this digest is produced

The digest is a byproduct, not a document anyone writes. Every item lives in the store with its fields (see appendix). The Monday edition is a query: everything with an event date in the coming week, everything captured in the past week, plus the active bills board, which renders every edition regardless.

**Design rules**

1. **Five-minute read.** Hard caps per section (below). If a section overflows, the review step demotes [NOTE] items; they stay in the store and the archive, just not the email.
2. **One line of editorial per item.** The "why it matters" field, maximum 35 words, in CitizenGO voice: direct, specific, no hedging. This is the layer that makes it ours.
3. **Every [ACT] has an owner and a deadline.** No orphaned urgency. If nobody owns it, it is a [WATCH].
4. **Links, not pasted text.** PQ answers, Hansard columns and bill documents are linked; full text lives in the store, searchable later. The digest never reproduces a full parliamentary answer.
5. **Empty sections are omitted**, with two exceptions: the Active bills board always renders, and during recess the digest switches to recess mode (bills board, open deadlines, intelligence notes, return dates).
6. **Priority tags:** `[ACT]` campaign or lobbying trigger this week, owner and deadline required. `[WATCH]` developing, no action yet. `[NOTE]` context only.

## Recess mode

When neither House sits for the full week: sections 1, 2, 6, 7 and 11 only, plus a single line of return dates. Deadlines do not respect recess; consultations and evidence calls stay prominent.

## Appendix: canonical record fields

Every captured item is one record. The digest, alerts, archive and MP profiles are all views of these fields.

| Field | Type | Notes |
|---|---|---|
| id | string | Source-prefixed, stable |
| captured_at | datetime | Ingest timestamp |
| source_feed | enum | whatson, bills, pq, hansard, votes, edm, committees, si, consultation, wms, devolved |
| item_type | enum | debate, question, division, amendment, stage, inquiry, si, consultation, statement, edm, petition |
| title | string | As published |
| url | string | Canonical link |
| legislature | enum | Commons, Lords, Holyrood, Senedd, NI Assembly |
| jurisdiction | enum | UK, England, E&W, Scotland, Wales, NI |
| event_date | date/null | When it happens (null for already-published items) |
| deadline | date/null | Evidence, consultation or prayer deadline |
| issue_areas | list | Taxonomy area numbers |
| matched_terms | list | For taxonomy maintenance |
| tier | enum | 1 or 2 |
| triage_score | int | 0 to 3 (Claude pass) |
| priority_tag | enum | ACT, WATCH, NOTE (human-set) |
| why_it_matters | string | ≤35 words, human-edited |
| owner | string/null | Required when ACT |
| action_status | enum | none, planned, live, done |
| mp_refs | list | Member IDs, feeds profiles and 5CA |
| bill_ref | string/null | Links item to a bills-board row |
