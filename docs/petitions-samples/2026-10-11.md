# Petitions and consultations: samples, 11 October 2026

SAMPLE. Built from the first live read of every source on 11 October 2026 into scratch stores (never the runner's store). Two parts: the edition section as it renders, and the campaign view (`tools/country_petitions.py <cc> --report`). Hand-checked against the sources' own pages for the items named in the scope docs.

A first read is the baseline: nothing already open counts as new, and no threshold counts as crossed without a count from before the window. So the edition extracts below use a longer window than a week (named in each heading) to show items that opened recently; from the second weekly run the window is the week, and threshold crossings and 10,000-signature weeks appear.
