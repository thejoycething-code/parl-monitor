# Brief Builder Learnings Log

Each test round: options shown per cell across the three test cases (AS, CT, DQ), the winner, why, and the rulebook change.

## Structural findings (2026-10-06)

1. **Template has evolved.** Current briefs (e.g. NI conversion therapy, Sep 2026) have per-series tabs (AA Classical Series, AA One-Button Extra Launch A/B, AA Text-Link…, FR OTD/MD…, OT Report Back, OT Call the Decision Maker, OT Organize an Event…) plus a **Zapier Data** tab mapping cells to copy placeholders: {{LANGUAGE}} {{CAMPAIGNER}} {{TARGET}} {{ASK}} {{WHAT-IS-HAPPENING}} {{KEY-INJUSTICE}} {{ARGUMENTS}} {{WHY-URGENT}} {{WHY-LISTEN}} {{BAD-OUTCOME}} {{GOOD-OUTCOME}} {{FUNDRAISING-OFFER}} {{SOURCES}} {{IMAGE-PROMPT}}, and OT-series placeholders {{GOAL}} {{WHAT-HAPPENED}} {{WHAT_ABOUT}} {{NUMBER}} {{WHAT-IS-NEW}} {{TWITTER-TARGET}} {{WHY-WORK}} {{EVENT-TYPE}} {{ORGANIZER}} {{WHY-EVENT}} {{WHY-COME}} {{WHY-ORGANIZE}}. → Cells are inputs to the copy generator, not only notes for the director. Rulebook must map to this template.
2. **5CA sheet has a `# Seats` column** (party rows with seat counts are now built in).
3. **The real NI brief diverges from several locked rules** (long Background with "PATH TO VICTORY" and probabilities; multi-part ask + suggested petition text; storytelling frame in What is happening; Obligatory type; launch to a Sub-List segment). Each is tested below as an option.
