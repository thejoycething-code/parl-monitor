## The index's notes on service

- Length of service: the parliament's own record of each member's periods (src/member_service.py; ch-council-history read 11 October 2026: every Nationalrat and Ständerat period since 1848 (MemberCouncilHistory)). 'Serving since' is the start of the current unbroken run of periods in the chamber, as the source dates them (a dissolution, a ministerial post or a resignation breaks it); 'at least' where it starts on the first day the source covers. A source that names terms only gives no 'since'. Nothing here says whether a term is a member's first.
